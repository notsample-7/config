# dotfiles

Application configs managed with [GNU Stow](https://www.gnu.org/software/stow/). Each subdirectory is a Stow package whose contents are symlinked into `$HOME` (`~/.config/<app>/...`).

## Usage

Restow everything:

```bash
stowall   # stow -t ~ *  from ~/config/dotfiles
```

Stow a single package:

```bash
cd ~/config/dotfiles && stow -t ~ <package>
```

Stop tracking / remove a package:

```bash
cd ~/config/dotfiles && stow -D -t ~ <package>   # unlink symlinks
git rm -r <package>                              # remove from repo
```

Add a new package (imports your current config):

```bash
mkdir -p ~/config/dotfiles/<package>/.config
cp -r ~/.config/<package> ~/config/dotfiles/<package>/.config/
cd ~/config/dotfiles && stow --adopt -t ~ <package>
```

## Exceptions

- **`opencode`** — only `opencode.jsonc`, `package.json`, `package-lock.json` and `AGENTS.md` are tracked; `node_modules/` stays untracked in `~/.config/opencode` (runtime dependencies). `AGENTS.md` is symlinked to `~/.config/opencode/AGENTS.md` and loaded globally by opencode.
- **`niri`** — only `config.kdl` is tracked. `noctalia.kdl` is generated by Noctalia and left untracked.
- **noctalia/matugen themes** — theme files rendered by Noctalia/Matugen (e.g. `bat/themes/noctalia.tmTheme`, `niri/noctalia.kdl`) are generated output and intentionally not tracked; they are regenerated at runtime from `noctalia/settings.json` and `user-templates.toml`. See `.gitignore`.
